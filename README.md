# 无尽田野 · 自动驾驶联合收割机

灵感来自《星际穿越》开头：尘土弥漫的天空、一望无际的玉米地、远处的群山、白色农舍，以及一台自动驾驶的联合收割机。
基于 Three.js 程序化建模，不依赖任何外部模型或贴图。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端里显示的地址（默认 http://localhost:5173）。地址后加 `?skip` 可以跳过片头。

## 内容

- **三块作物田**：玉米（约 4.2 万株）、小麦（约 5.5 万丛）、大豆（约 3.7 万株），每株都是独立几何，近处高精度、远处低精度（分块 LOD），带风吹摆动；收割后变成茬并留下秸秆痕迹。
- **联合收割机**：人字纹轮胎、后轮转向、可升降过桥、两种割台（8 行玉米割台 / 9.1 m 谷物割台，带旋转拨禾轮和弹齿）、绞龙、粮仓粮堆、可摆出的卸粮搅龙、驾驶室内饰、激光雷达 / GNSS / 摄像头自动驾驶套件、警示灯、夜间工作灯。
- **自动驾驶**：按割幅规划往返作业带，地头用 Dubins 曲线掉头，纯追踪（Pure Pursuit）跟踪路径；粮仓将满时自动开到运粮车旁卸粮，然后回到田里继续；三块田依次收完后返回农场。
- **环境**：带 HDR 地平线尘雾的天空、积雪远山、远景作物田、农舍、谷仓、粮仓、风车、电线杆、防风林；可调时间（含星空与月光）、沙尘暴、秸秆 / 扬尘 / 谷物流粒子、胶片调色、程序合成音效。

## 操作

| 按键 | 功能 |
| --- | --- |
| P | 自动 / 手动驾驶切换（手动时按 WASD 也会自动接管） |
| W / S | 前进 / 后退 |
| A / D | 转向 |
| 空格 | 刹车 |
| E | 升降割台（放下后驶入作物即可收割） |
| H | 切换玉米 / 谷物割台 |
| U | 展开 / 收起卸粮搅龙 |
| C 或 1–4 | 视角：跟随 / 驾驶室 / 电影 / 自由 |
| T | 作业倍速 1× / 2× / 4× / 8× |
| L / F / M | 车灯 / 沙尘暴 / 声音 |
| R | 车辆复位 |
